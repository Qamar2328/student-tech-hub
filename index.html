How Flexbox is Used

CSS Flexbox is a layout system used to arrange elements in rows or columns. In this webpage, Flexbox is used for the navigation menu and technology cards.


  • display: flex; creates a Flexbox container.
  • justify-content controls the arrangement of items.
  • align-items controls the alignment of items.
  • gap creates space between items.
  • flex-wrap allows items to move to another line.
  • flex-direction changes the direction of items.

Responsive Web Design

Responsive web design allows a webpage to adjust according to different screen sizes such as desktops, tablets and mobile phones.


In this webpage, media queries are used to change the Flexbox layout when the screen becomes smaller. On a desktop, cards appear next to each other. On a mobile device, cards appear vertically.

Flexbox Features

  • display: flex - creates a Flexbox layout.
  • flex-direction - controls row or column direction.
  • justify-content - controls main-axis alignment.
  • align-items - controls cross-axis alignment.
  • gap - adds space between items.
  • flex-wrap - allows items to move to another line.
